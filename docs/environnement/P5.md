## Écarts et problèmes rencontrés

| Problème | Cause | Solution appliquée |
|---|---|---|
| `uv` et Node.js absents du poste | document 01, parties 2.4 et 2.5 non faites | `uv` 0.12.18 installé par l'installateur officiel dans le dossier personnel ; Node.js installé depuis l'archive officielle `node-v24.21.0-darwin-arm64.tar.gz` plutôt que par le paquet `.pkg`, empreinte SHA-256 vérifiée contre `SHASUMS256.txt` de nodejs.org, décompressée dans `~/.local/node` — même version exacte, sans privilège administrateur, comme le prescrit la fiche pour Linux |
| `python -m scripts.verifier_poste` affichait « VS Code : ABSENT » alors que VS Code est installé | le script appelle `code --version`, et l'outil en ligne de commande de VS Code n'est pas dans le `PATH` par défaut sur macOS | ajout de `/Applications/Visual Studio Code.app/Contents/Resources/app/bin` au `PATH` dans `~/.zshrc` ; le relevé affiche désormais la version |
| Premier `hf auth login` fait par navigateur | l'option « Log in with your browser » crée un jeton OAuth sans rôle lisible ; `tester_hf` affichait « rôle du jeton « inconnu » » et un avertissement | reconnexion avec « Paste an access token » et un jeton **Read** nommé `nlp-a3b1-P5` ; le rôle attendu `read` est désormais retourné |
| Mémoire de 8 Go | poste prévu par l'hypothèse H3 du plan | sans effet sur le volet A ; pour le volet B (MOBOTU-31), le dimensionnement de la décision D4 estime la chaîne à 3,9–4,5 Go et impose de fermer les applications lourdes pendant l'exécution, avec repli `-c 3072` puis Q3_K_M |
